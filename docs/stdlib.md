# squark standard library reference

Generated by `squark doc std` (run `docs/gen.sh` to refresh). Signatures include reference
provenance: `from p` means a result may point into what `p` refers to, `x T into p` means
`x` may be stored inside `p`, `static` means static memory only. Methods follow their type.
